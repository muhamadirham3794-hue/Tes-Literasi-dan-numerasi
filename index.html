Panduan Integration Apps Script & GitHub

Simpan data Pre-Test & Post-Test murid ke Google Sheets & hosting gratis via GitHub Pages.

1 Google Apps Script (Penyimpanan Pre & Post Test)

Buat Google Spreadsheet baru → Klik Ekstensi → Apps Script. Tempel kode berikut lalu Deploy sebagai Web App (Anyone): 

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  sheet.appendRow([
    new Date(),
    data.testType, // Pre-Test atau Post-Test
    data.studentName,
    data.gender,
    data.studentClass,
    data.jenjang,
    data.scoreLiteracy + "/25",
    data.literacyCategory,
    data.scoreNumeracy + "/25",
    data.numeracyCategory,
    data.recommendation
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({result: 'success'}))
    .setMimeType(ContentService.MimeType.JSON);
}
